# EvoSim

EvoSim is an interactive evolutionary simulation project built as a
software engineering portfolio project.

The project is being developed incrementally, starting with a Java
simulation engine and later expanding into a Spring Boot backend and
React + TypeScript frontend.

## Current Status

V1 development — Project Foundation.

## Planned V1 Stack

- Java 21
- Maven
- JavaFX (temporary debug viewer)
- Spring Boot
- React
- TypeScript
- HTML Canvas
